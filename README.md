# Northlight Archive — Photography Store

A GitHub Pages storefront with:
- Searchable photographs and tags
- Categories / collections
- Shopping cart
- Supabase authentication for a private admin dashboard
- Supabase database + storage
- Original files stored privately
- PayPal checkout with Venmo eligibility
- Automatic order recording
- Download links after successful payment

## IMPORTANT
GitHub Pages is only the frontend. Do not put a PayPal client secret or Supabase service-role key in this repository.
The included Supabase Edge Function is the secure backend.

See `SETUP.md` for the complete setup.
